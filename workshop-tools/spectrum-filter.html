Move the pointer over the plot to read observed wavelength and see which filters (from the sets enabled above) contain it — including gaps where no enabled filter covers a feature.

Continuum shapes and line ratios are stylized to be representative of each class (UV/optical slope, Balmer/4000Å break behavior, PAH complex, hot-dust/torus rise, nebular line ratios) — this is a pedagogical tool, not a stellar-population-synthesis or photoionization model. Filter wavelength ranges are approximate (roughly FWHM) bandpasses for JWST NIRCam / MIRI, HST ACS / WFC3, and representative ground-based imagers (Subaru HSC, VISTA); consult the relevant instrument handbook for precise throughput curves before using this for proposal-grade planning. Flux is in arbitrary units and includes only a rough 1/(1+z) surface-brightness dimming term, not a full cosmological k-correction.
